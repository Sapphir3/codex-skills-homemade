# 手写笔记格式与关键词

## 最小习惯

每页写日期和主题，用短标签区分打算做、实际做、看到的现象和个人解释。现场可按时间推进，转换时再整理；不要求按成稿章节书写，空类别可以不写。

| 标签 | 用途 | 示意（合成示例） |
| --- | --- | --- |
| 【目的】 | 要回答的问题 | 比较两种固定方式是否影响泄漏 |
| 【计划】P1 | 当日任务及状态 | √ P1 制作夹具；× P2 测试 → 明天 |
| 【对象/参数】 | 对象及所属参数 | 样品A：下一行缩进写长度、浓度等 |
| 【操作】 | 确实执行的步骤 | 14:10，实际加入溶液…… |
| 【观察】O1 | 直接见到/测到的现象 | 14:15，接口出现液滴 |
| 【计算】C1 | 理论量、公式和估算 | 理论加入量 = ……；实加量另列 |
| 【问题】Q1 | 异常、疑点、未解释现象 | Q1（O1）：为什么接口渗漏？ |
| 【猜想】H1 | 可能原因或解释 | H1（解释Q1）：可能是接头未贴合？ |
| 【下一步】N1 | 拟议验证或行动 | N1（检验H1）：重新固定后复测 |
| 【数据】 | 文件与样品/步骤的对应 | img_A_01，对应O1 |
| 【更正/补记】 | 纠错或事后新增信息 | 日期 + 原值 → 新值 + 理由 |

这些标签不必全部使用；原有“计划”“问题”“猜想”等自然文字也有效。编号只在关系复杂时使用。

## 计划符号

- `□`：待做，尚未填写结果。
- `√`：当日完成，仍然是一项计划。
- `×`：当日未完成；不能默认理解为取消或实验结果为阴性。
- `→ 日期`：明确延期安排，不自动补“后来已完成”。
- 取消写“取消”，失败写“已执行但失败”，避免所有状态都只用叉号。

先将图例写在笔记本首页，不能将一位作者的图例套用于所有笔记。旧数值用单横线划掉并写“更正”，避免和任务前的叉号混淆。

## 缩进与归属

父项单独占行，子项右缩一个明显格距；同级左对齐，换对象时退回父级并空行。例如：

```text
【参数】材料A（理论/参考参数）
    浓度：……
    孔径：……
    D：……
    k：……
【参数】材料B（实测）
    D：……
```

不要让 D、k 漂浮在两个对象中间。跨页写“续：材料A参数”。给分子分母、指数、负号和单位留足空间，一行尽量只写一条完整关系。

## 理论量、实际量与颜色

配液表推荐列：`组分 | 理论量（单位） | 实际加入量（单位）`。目标浓度、母液标识和配制日期写在表头附近，不靠隐含计算决定一列归属。

可以继续用黑笔理论量、蓝笔实际量、红笔问题/思考，但要写图例，关键处仍加“理论”“实加”“问题”“猜想”等文字。颜色只是辅助，不同颜色不自动表示修订。

## 分析链条

先写观察 O1，再写问题 Q1、猜想 H1，最后写拟议行动 N1；用编号或明确箭头连接。尚无原因或下一步时不必补齐，多个猜想可以并列。

【问题】与【猜想】即使在页底或红笔旁注，也属于实验记录主体。转换应保留完整条目、问号和条件；归纳只改变组织方式，不增加原稿没有的解释。

## 人工复核

优先核对数字+单位+指数、样品/配方归属、计划状态、观察与猜想边界，以及遗漏的整段分析。反馈用“页/区块 + 原读法 + 正确读法”；新信息明确标为补记。

可从 [单页书写模板](../assets/HANDWRITING_TEMPLATE.zh-CN.md) 开始，只保留适合自己的标签，不必牺牲现场记录速度。
